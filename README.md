# RuneDefence
A tower defence minigame in the RuneLite sidebar. Recruit defenders, place them beside the path and hold out against up to 99 waves, across seven maps. All art is original.

## Levelling up
Every 10 OSRS XP you gain, in any skill, earns 1 RuneDefence XP. You can lower that to as little as 1 in the plugin settings to level faster. RuneDefence levels unlock new defenders, all the way to Zuk at level 99, and new maps. Gold only exists inside a match, so a high level unlocks options rather than power.

Only XP gained while you're logged in with the plugin on counts. XP you already had doesn't.

Reaching level 99 takes 130,344,310 OSRS XP at the default setting, or 13,034,431 at the fastest.

## Settings
| Setting | What it does | Default |
| --- | --- | --- |
| Auto-start waves | Starts the next wave by itself after the delay below. You always start the first wave of a match by hand. | On |
| Delay between waves | How long to wait before auto-starting the next wave, from 3 to 120 seconds. | 15 seconds |
| Pause on logout | Pauses the match when you log out of OSRS, and resumes when you log back in. | On |
| Pause when panel hidden | Pauses the match while another sidebar panel is open. | On |
| Pause when RuneLite loses focus | Pauses the match while you're using another window. | Off |
| Battle effects | Shows hit numbers, blasts and death puffs. | On |
| Level-up messages | Adds a chat message when your RuneDefence level rises. | On |
| OSRS XP per RuneDefence XP | How much OSRS XP earns 1 RuneDefence XP, from 1 (fastest) to 10 (slowest). | 10 |

Changing **OSRS XP per RuneDefence XP** recalculates your level from all the XP counted so far, so your level can go up or down. You never lose XP, and matches you've already started carry on.

## Your data
RuneDefence never sends game input and makes no network requests. Progress is kept in your RuneLite settings, separately for each OSRS character. You can play before logging in, but nothing is saved until you log in.
